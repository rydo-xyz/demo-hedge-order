# Hedge & Order — DEMO ONLY

**Fictional brand** built for the **Kerbstone Studio** portfolio to demonstrate a Spark-tier one-page garden / lawn website.

- Not a real business
- Towns, packages, and prices are invented
- Before/after strip uses CSS/SVG — no real client photos
- Do **not** present this as a live client

## Stack

Static HTML / CSS / tiny JS. Netlify Forms on the quote form (`data-netlify="true"`).

## Deploy

See `/workspace/demos/BUILD.md`. Publish directory is `.` (this folder). No custom domain.

## Local preview

Open `index.html` in a browser, or serve the folder with any static server.
